QR Contact Generator

Приложение для создания QR-кодов визиток в формате vCard.

Возможности
Генерация QR-кода контакта
Поддержка нескольких телефонов
Email
Telegram
WhatsApp
Instagram
Веб-сайт
Сохранение QR в PNG
Экспорт контакта в VCF
Технологии
Python
CustomTkinter
qrcode
Pillow
Запуск
pip install -r requirements.txt
python main_v3.py
